Six-month poststroke depression (n = 115, 26%) was associated with 6-month impairment on the MoCA (beta = 0.96, standard error [SE] 0.31, p = 0.006) and all individual domains assessed by the OCS: spatial attention (beta = 0.67, SE 0.33, p = 0.041), executive function (beta = 1.37, SE 0.47, p = 0.004), language processing (beta = 0.87, SE 0.38, p = 0.028), memory (beta = 0.76, SE 0.37, p = 0.040), number processing (beta = 1.13, SE 0.40, p = 0.005), and praxis (beta = 1.16, SE 0.49, p = 0.028).
