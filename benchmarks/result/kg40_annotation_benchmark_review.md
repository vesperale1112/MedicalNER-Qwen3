# 40 篇知识图谱标注与 benchmark 全量检查报告

## 结论与检查范围

主要问题不只是 Codex 的分数低。**现有评分把“抽取覆盖、实体命名、实体类型、关系标签和方向”共同折叠成一个精确匹配结果；而三份人工标注在这些方面本身也有明显差异。** 此外，部分证据字段无法直接定位为连续原文，个别关系需要核实证据与语义是否相符。Codex 自己也存在覆盖不足的问题，不能把低分全部归因于人工标注或评分方式。

本报告针对 40 篇文章的标题和摘要，检查 DHY、尤雅、标注员三份原始标注的 benchmark 转换文件，以及本次 Codex v3.1 草稿。检查覆盖全部 40 篇的图结构、类型、关系、证据字符串、人工之间的精确重合和逐篇得分；对报告中的具体语义例子回看了对应摘要和标注。**没有完成 1,509 条关系的逐条医学真伪仲裁，也没有对论文全文进行审核**；因此表中的结构统计不等于正确率，示例也不能外推为全部同类关系都错误。

用户已确认第三位标注员的工作已完成，只是导出状态未更新；原始 JSON 中仍保留 `in_progress` 字段，不据此判断其未完成。三份标注均未经过多人仲裁。Codex 草稿是助手编写的预测，不是独立模型推理；此前对话已查看过旧版抽取，也不能视为严格盲态实验。

可核对明细：

- [40 篇逐篇统计表 CSV](kg40_article_audit.csv)：每人的实体、关系数量，三人精确交集，以及 Codex 对每份参考的关系 TP/FP/FN。
- [全部关系及证据检查 CSV](kg40_relation_evidence_audit.csv)：1,509 条原始关系，包含文章、标注者、关系两端、证据和可自动检查的字段。`not_contiguous` 只表示不能在输入中找到连续字符串，不等于证据错误；`short_evidence_under_15_chars` 是定位极短证据的线索，不是正确性判决。
- [五篇案例可视化](kg40_codex_v3.1_cases.html)、[三次 benchmark 的指标汇总](kg40_codex_v3.1_benchmark.md)。

## 1. 三份人工标注的覆盖范围差异很大

| 数据 | 实体原始条数 | 关系原始条数 | 实体去重后 | 关系去重后 | 非空属性数 |
|---|---:|---:|---:|---:|---:|
| DHY | 479 | 464 | 479 | 464 | 74 |
| 尤雅 | 336 | 299 | 335 | 299 | 18 |
| 标注员 | 429 | 536 | 429 | 536 | 741 |
| Codex | 295 | 210 | 295 | 210 | 0 |

统计单位是“文章内实体或关系”，不是全语料去重后的医学概念；去重方式与当前评分器一致。三人并非关系越多就越正确：不同人可能选择不同粒度，也可能有遗漏或过度推断。

几个差异明显的文章：

- **98091，抑郁症治疗指南**：DHY、尤雅、标注员分别有 8、0、9 条关系。尤雅有 2 个实体但没有关系；其他两份与 Codex 都建有指南相关关系。需要按统一范围复核，并不因某人关系为 0 就推断其标注状态或原因。
- **57744，围产期指南**：分别为 21、1、37 条关系；该摘要包含筛查工具、治疗和共同决策等多个方面，覆盖范围差异会直接改变 benchmark 的参考分母。
- **128282，抑郁症治疗指南**：分别为 22、6、29 条关系；Codex 为 7 条。指南区分不同严重程度及初始治疗无效后的选择，Codex 草稿没有完整表达这些条件；但参考之间也有明显的范围和建模差别，不能单凭数量确定正确答案。

前、后 20 篇的人工作图数量也并不均衡：DHY 关系数为 193 / 271，尤雅为 171 / 128，标注员为 172 / 364。文章主题和长度不同，**这些数字不能证明某一批标错或使用了另一版 schema**，但提示正式汇总前应查看分批及按文章类型的结果。

## 2. 人工之间的严格重合有限，单人参考会显著影响分数

这里用现有 `graph` 规则，分别把一份人工图与另一份人工图进行对照；F1 是集合精确匹配的 micro F1，不是 Cohen's kappa，也不是医学正确率。

| 人工两两对照 | 图实体 micro F1 | 图关系 micro F1 |
|---|---:|---:|
| DHY / 尤雅 | 0.545 | 0.286 |
| DHY / 标注员 | 0.546 | 0.334 |
| 尤雅 / 标注员 | 0.469 | 0.184 |

按文章内的“起点类型和名称 + 关系名 + 终点类型和名称”去重，三人关系并集为 **1,012** 个，其中 **66** 个被三人严格共同标注，**791** 个只出现在一份标注中。40 篇中有 **19 篇**没有任何三人共同的严格关系键。这个数字混合了同义写法、类型或方向不同、标注范围不同等原因；**不能解释为只有 66 条医学上正确，也不能直接作为正式的标注一致性系数**。

Codex 对三份参考的图关系 micro F1 分别是 **0.172、0.130、0.177**；实体分别为 **0.380、0.327、0.406**。有 **17 篇**在与三份参考分别比较时关系 TP 均为 0。这里的 0 指严格键没有命中，不代表文中没有抽出任何有用事实。

## 3. 实体名称和缩写会造成连锁失配

当前评分器对名称只做 Unicode NFKC、大小写和空白规范化，不做同义词、缩写、括号或概念映射。关系必须同时匹配两端名称、两端类型、关系名及方向；只要端点名字不同，依赖该端点的关系也不会命中。

- **154547，ADHD 试验**：三位人工均用 `SPN-812 (viloxazine extended-release)`，Codex 用 `viloxazine extended-release`。三人和 Codex 都有该药与 `somnolence`、`decreased appetite`、`headache` 的不良事件关系，但 Codex 与三份参考的该篇关系 TP 均为 0。至少这三条的匹配受到药物端点名称差异影响；其他关系也有疾病名、量表名和端点范围差异。
- **164994，ECT 研究**：Codex 用 `electroconvulsive therapy`，人工使用 `electroconvulsive therapy (ECT)`。两边均出现 ECT 与药物的 `combined_with` 表达，但不会严格命中。原文是褪黑素和美金刚分别分组，与 ECT 同期使用，不能解释成两药同时联用。
- **131854，抑郁症试验**：`treatment-resistant depression` 与 `treatment-resistant depression (TRD)` 不匹配；同篇四个以药物和相同症状名称表示的不良事件关系可命中，说明不是该篇所有关系都无法匹配。

这些是确认的字符串或类型差异，**不是自动证明语义等价或某人标错**。适合在保留严格结果的基础上，另设经过人工验证的别名/概念映射比较；不能粗暴删除所有括号或自动把相似名称合并。

## 4. 实体类型和关系建模粒度不一致

- **167942，帕金森病综述**：同名 `apathy` 在 DHY 图中是 `Disease`，在尤雅、标注员与 Codex 图中是 `Symptom`。不同类型导致即使名称相同也不能匹配。摘要讨论精神症状或共病与后续结局的关联，应先明确此类现象的建模规则，而不是只在评分时改名。
- **131814，精神分裂症试验**：DHY 和标注员将复方 `xanomeline-trospium chloride (KarXT)` 建为 `Medication`，尤雅将 `KarXT: xanomeline-trospium chloride` 建为 `Treatment Plan`；Codex 使用不带缩写的 `Medication`。因此同一治疗及其不良事件边既可能因类型，也可能因名称不一致而失配。
- **128282，指南**：有人将单药、联合治疗、不同人群和后续方案拆成多个 `Treatment Plan` 与 `Patient`；Codex 主要描述指南、治疗和药物。两者图的粒度不一致，导致只做名称规范化仍不足以解决全部差异。
- **107246，恶性紧张症病例**：尤雅图有两个 `Symptom: negativism` 节点，分别连向不同疾病和不同原文证据。当前实体评分按文章内“类型＋名称”将其去重为一个，因此 27 条原始实体变成 26 个计分实体。两个节点可能对应不同上下文，不能简单称为重复错误；现有 graph 任务不能保留提及级别的时间或上下文区别。

另外，三人分别录入 74、18、741 个非空属性，但当前 `graph_entity`、`graph_relation` 不把属性计入匹配；关系的 `evidence` 也不进入得分。因此属性丰富程度和证据质量不会反映在当前 P/R/F1 中。没有人工复核方案时，不应将它们称作已测得的属性抽取或证据正确率。

## 5. 证据字段：可定位不等于支持关系

| 数据 | 关系数 | 证据是输入的连续原文 | 仅规范化后连续匹配 | 规范化后仍非连续匹配 |
|---|---:|---:|---:|---:|
| DHY | 464 | 464 | 0 | 0 |
| 尤雅 | 299 | 299 | 0 | 0 |
| 标注员 | 536 | 507 | 2 | 27 |
| Codex | 210 | 210 | 0 | 0 |

连续匹配只检查证据字符串是否存在于文章标题＋摘要，不检查这段文字能否支持关系。27 条未连续匹配的记录分布在 **11 篇**；其中可见以省略号拼接不同位置的证据，也有需要逐条核对的改写。非连续拼接可以包含有用信息，但不能直接当成单一可定位的原文片段。

另外，在标注员的 507 条连续匹配中，有 **6 条证据字段仅为 `1`**，分布于 **130406、131651、107246**，每篇 2 条。数字 `1` 恰好出现在输入中，因此字符串检查会将其计为“连续匹配”，但它不是可供判断这些关系的充分上下文。比如 131651 中 `depressive symptom → is_symptom_of → prenatal insomnia` 和 `anxiety symptom → is_symptom_of → prenatal insomnia` 的证据均是 `1`；这些边及其证据需要人工回到原文复核。

## 6. 关系标签、试验结论和证据强度需要结合原文复核

以下是已经定位到的具体复核点；不是对某一标注者整体质量的推断。

1. **131814，复方药物的单一组分。** 尤雅图中有 `trospium chloride → therapeutically_indicated_for → schizophrenia`；引用证据说的是该成分与 xanomeline 组合，目的是减少后者的外周不良事件。该摘要片段本身并未说明 trospium 单药被证明或获批用于治疗精神分裂症，建议核对是否应只建复方或组合关系。
2. **131814，治疗期间事件与因果。** 尤雅图把复方与 `somnolence`、`extrapyramidal symptoms` 连为 `causes_side_effect`，所给证据同时写明两组相关指标相似。两组相似并不能证明完全没有药物作用，但该句本身不足以直接确立“由该药导致”；同样，其他人和 Codex 将 treatment-emergent adverse events 表达成 `causes_side_effect` 时，也应先统一是否允许此类从事件到因果的映射。
3. **190928，风险因素与因果。** 三份人工图均包含童年创伤或物质使用对精神分裂症谱系障碍的 `contributes_to` 关系。摘要提到相关性，并谨慎提出可能与发病基础有关；`contributes_to` 是否需要明确因果证据，必须由标注规范定义，不能把“相关”直接视为已证实因果。Codex 在该篇只保留了遗传易感性和环境因素两条关系，也可能遗漏有价值的弱证据表达。
4. **241700，检查触发。** 标注员图中有 3 条临床哺乳评估 `triggers_examination` 浓度检查；摘要描述纳入研究测量的母体、乳汁和婴儿浓度。是否足以表达为临床评估“触发”检查，需要进一步核对，不能仅因检查在研究中出现就认定有触发关系。
5. **130960，治疗方案组成。** 标注员将 measurement-based care 建为包含 paroxetine 和 mirtazapine 的治疗方案。原文写明两种药物是两组共同允许的药物，MBC 的区别是重复量表测量并用于指导调药；这两条 `consists_of_medication` 是否表达了方案组成，需明确建模约定。Codex 本次没有保留这两条，但不因此自动证明它的表示更完整。
6. **130406，否定与试验结论。** 摘要明确说 DCS 未增强 ERP 的效果。可以表示研究中 ERP 与 DCS 联用，但不应把“联合使用”直接改写为“DCS 增强了疗效”。这也说明图中若缺乏极性、研究对象与证据强度，单看边容易丢失关键语境。

## 7. 数据和评测实现的边界

- 40 篇四份输入的文章 ID 和文本一致；按 v3.1 的实体类型及关系端点组合检查，三份人工和 Codex 都没有发现非法类型或端点组合。但**结构合法不代表原文支持或医学判断正确**。
- 当前 graph 实体匹配按类型和名称；关系要求带方向的两端与关系名均一致。它不检查证据、否定、研究阶段、适用人群和属性，也不自动识别同义名称。
- 本批没有完整的字符级 mention 和标准概念 ID，因此目前分数不是 NER、NEL、M-RE 或 C-RE，也不能称为 GutBrainIE 官方成绩。
- 参考由单个标注者分别提供、尚无仲裁；报告的是“相对某份人工图的匹配”。参考未列出的边在当前评分中可能被计 FP，但不能直接说明原文不支持。
- 对本次 Codex 草稿，40 篇有 295 个实体和 210 条关系，且后 20 篇只有 91 条关系，明显少于 DHY 的 271 和标注员的 364；其中可能有真实漏抽，也可能反映粒度或保守程度不同，需逐条复核，不能将数量差直接等同于漏抽数量。

## 8. 建议优先处理顺序

1. **先约定标注范围与关系语义**：实体类型、复方药物与方案、量表与维度、指南与人群；区分已获批/推荐与试验性使用、治疗期间事件与因果副作用、相关与因果、否定或无显著差异。
2. **对分歧大或疑似证据不足的条目仲裁**：优先查 6 条 `1` 证据、27 条非连续证据，以及前述具有具体原文依据的语义复核点。保存原始标注、仲裁决定和证据，不静默改写。
3. **建立可追踪的名称与概念映射**：先针对药物、疾病和量表人工确认简称及同义词；同时报告严格匹配和映射后的结果，说明覆盖率及无法映射的类别。
4. **先形成明确的参考集，再评价模型**：明确哪些关系必须标、哪些保留未知；将人工间一致性与 Codex 对仲裁集的成绩分开。比较不同模型时固定文本、schema、参考版本与评分规则。
5. **拆开报告指标**：除了当前端到端图实体与关系精确匹配，单独评估类型/schema 合法性、证据支持、关系极性和条件；有可用标注时再评估属性、字符位置和概念链接。不能从当前 graph F1 推算这些指标。
