# 知识图谱抽取 benchmark：论文重点与建议方案

更新：2026-10-26。依据本目录 8 篇论文 PDF 的正文，补充 CDR 官方论文。以下方案供讨论，尚未执行。

**建议：以自建人工金标测试集为主，配一个难例集，再用一个公开数据集做外部对照。** 要回答的是：给模型一段原文，它能否找全实体、连对关系，并给出真正支持这条关系的证据。

**一、具体指标设计**

这些论文大多比较的是**模型输出与人工标准答案的匹配程度**。需要区分三件事：

- **抽取正确性：** 预测实体/关系与金标是否匹配，用 Precision、Recall、F1。
- **原文支持程度：** 人工判断预测是否被原文支持；即使金标漏了，它也可能是正确事实。
- **一致性：** 两位标注者是否判断相同，或同一个模型多次运行是否稳定。这不能代替正确性。

设预测集合为 A，金标集合为 G。按下文各论文的规则匹配、去重后：

```text
TP = 匹配成功的预测数
FP = 未匹配金标的预测数
FN = 没有被预测命中的金标数
Precision = TP / (TP + FP)
Recall    = TP / (TP + FN)
F1        = 2TP / (2TP + FP + FN)
```

例如，金标有 10 条关系，预测 8 条，其中 6 条匹配：TP=6、FP=2、FN=4，P=75%、R=60%、F1≈66.7%。**把关系标签写错，通常同时增加一个 FP 和一个 FN**；只认出两个实体并不能给这条关系加分。

**micro F1** 先汇总所有文档/类别的 TP、FP、FN 再算；**macro F1** 先算各类别 F1 再平均，让少见类别也有同等权重。不同论文的“类别”和“匹配规则”可能不同，必须连同分数一起看。

**二、数据、方法、评测对象与算法**

**1. MDKG / MDIEC（Nature Communications，2025）**

- **数据：** 精神障碍相关 PubMed 摘要。论文描述人工复核 500 篇，构成 MDIEC；按固定训练/验证/测试划分评抽取。论文正文与本次下载包的规模有差异，见后文，不应自行假定划分比例。
- **方法：** BERN2、词典和 GPT 辅助预标注，人工修订，并用主动学习选下一批标注文本。抽取模型是 **SpERT.PL + CODER++ 编码器 + NoisyTune**，联合识别实体和关系；之后用 GPT-4o 检查实体边界、类型和关系、修订三元组。并非单纯让一个 LLM 零样本生成整张图。
- **自动评测：** 分开报告实体识别、关系抽取、联合抽取的 P/R、micro/macro F1。实体 micro F1=0.89，关系=0.68，联合=0.63；后处理后报告联合=0.79。**正文没有完整展开各任务的 TP 匹配细则，例如关系单项是否固定金标实体、是否允许边界宽松匹配；仅靠正文不能补写成确定的评分协议。** 复现时需继续核对实现/补充材料。
- **人工评测：** 在精神分裂症、焦虑障碍各抽 100 条不重复三元组，由 2 名精神科医生和 2 名医学博士评判。正确性依据提供的句子，正确率为“判断正确的条数 / 被评条数”；另打 1–3 分的启发性评分，记录耗时。PrimeKG 缺原始来源，未参与正确性评分。
- **一致性怎么算：** 评审者两两计算一致率，以及 Cohen’s κ：`κ=(实际一致率−随机预期一致率)/(1−随机预期一致率)`。这里是**人和人的判断一致性**，不是实体/关系 F1。人工正确率 79% 与后处理联合 F1 0.79 也是两个独立指标。

**借鉴：** 自动抽取指标与人工证据复核并行；不能把人工正确率当作召回率。[论文](https://doi.org/10.1038/s41467-025-62781-z) · [PDF：Methods、Comparative evaluation](../references/mdkg_2025.pdf)

**2. GutBrainIE（Findings of EACL，2026）**

- **数据：** 肠脑轴文献 1,647 篇，898 篇人工标注、749 篇自动标注。开发/测试各 40 篇，仅用专家标注；其余训练材料包含专家、受训非专家和自动标注。实体有 13 类。
- **方法：** 基线用 **GLiNER** 抽实体，**ATLOP** 读取原文和预测实体后抽关系；再做词表/概念链接。NER 用人工质量层训练，RE 还使用自动标注作为远程监督。
- **具体如何算 TP：** 四个任务都与金标逐项匹配，满足全部字段才计 TP：

| 任务             | 必须匹配的内容                                               |
| ---------------- | ------------------------------------------------------------ |
| NER，实体识别    | 所在部分（标题/摘要）+ 字符起止位置 + 原文片段 + 实体类型    |
| NEL，实体链接    | 上面所有字段 + 规范概念 URI                                  |
| M-RE，提及层关系 | 主体原文片段 + 主体类型 + 关系标签 + 客体原文片段 + 客体类型 |
| C-RE，概念层关系 | 主体 URI + 主体类型 + 关系标签 + 客体 URI + 客体类型         |

例如，“Parkinson”与“Parkinson’s disease”在 M-RE 下不能仅凭同义算匹配；在 C-RE 下，若链接到同一 URI，其他字段也一致，就能匹配。**M-RE 的五元组不是 NER 那套完整字符位置匹配，不能混写。**

- **汇总：** 去重，重叠预测按论文规则合并并保留最长片段，再算 micro/macro P/R/F1。NER/NEL 的 macro 按 13 类实体；关系的 macro 按 55 种“主体类型—关系—客体类型”组合。主指标是 micro F1。

**借鉴：** 同时保留精确定位和概念层评分，能区分“边界不一样”与“医学概念真的抽错”。[论文](https://aclanthology.org/2026.findings-eacl.301/) · [PDF：§2、§4](../references/gutbrainie_2026.pdf)

**3. Zero-shot biomedical RE（WASP，2025）**

- **数据：** 7 个医学 RE 数据集：ADE（药物不良事件）、DCE（药物组合）、ChemProt（化学物质—蛋白）、DDI（药物相互作用）、CDR（化学物质诱发疾病）、GDA（基因—疾病）、BioRED（多类型医学关系）。评完整测试集，保留数据集本身含有的无关系样本。
- **方法：** GPT-4、o1、GPT-OSS-120B **不做任务微调**，接收原文、任务说明与 JSON 格式要求，直接抽出关系及其实体。对 GPT-4 还比较两种结构输出方式。
- **提及层评测（ADE/DCE/ChemProt/DDI）：** 预测中的实体提及要匹配金标提及，实体类型、关系类型也要正确，才算整条关系 TP。DCE 是多药物组合，不能一概降成普通二元关系；它另报“正向有效组合 F1”和“任意组合 F1”，后者合并正向与非正向组合。
- **概念层评测（CDR/GDA/BioRED）：** 每个预测端点可匹配该金标概念的任一已标注名称；匹配后用金标映射到概念 ID，再去重、计算关系 P/R/F1。不是调用另一个 LLM 自由判断同义。
- **评测的是什么：** 是**从原文开始的端到端关系匹配**，实体抽错会使关系失败；核心结果不是单独的实体 span F1，也不是图形相似度。BioRED 关系按其原生无向定义处理，不能套上我们所有关系都有方向的规则。

**借鉴：** 必须明确匹配的是字符位置、名称还是概念 ID；即便都叫 F1，也可能不是同一道题。[论文](https://aclanthology.org/2025.wasp-main.6/) · [PDF：§2.3–2.4](../references/zero_shot_biomedical_re_2025.pdf)

**4. BioRED（Briefings in Bioinformatics，2022）**

- **数据：** 600 篇 PubMed 摘要，train/dev/test=400/100/100；6 类实体、8 类关系，同时标注关系属于新发现还是背景知识。标注由多人复核、仲裁。
- **方法：** NER 比较 BiLSTM/BioBERT/PubMedBERT + CRF；RE 比较 BERT-GT 与 PubMedBERT 分类模型。**RE 实验输入金标概念**，并不承担上游实体漏检的损失。
- **实体评分：** 严格匹配要求实体边界和类型正确；宽松匹配允许边界重叠，但类型仍须正确。两者分别统计 TP/FP/FN、算 P/R/F1。
- **关系评分：** 逐级增加匹配条件：① 两个概念 ID 配对正确；② 还要求关系类型正确；③ 再要求新发现/背景标签正确。每一级分别算 P/R/F1，不能只连对实体就算第②级正确。
- **结果说明：** 最佳模型在第②级 F1=58.9%，第③级降到47.7%，表明“知道谁和谁有关”与“准确描述关系及性质”难度不同。

**借鉴：** 将关系端点、类型、附加属性的错误拆开。它的给定实体关系成绩不能直接比较我们的全流程成绩。[论文](https://doi.org/10.1093/bib/bbac282) · [PDF：§3.3、§4](../references/biored_2022.pdf)

**5. Text2KGBench（2023）**

- **数据：** 通用领域，不是医学：Wikidata-TekGen 有 10 个本体、13,474 个句子；DBpedia-WebNLG 有 19 个本体、4,860 个句子。每个句子配标准三元组。
- **方法：** Vicuna-13B、Alpaca-LoRA-13B 接收任务指令、本体、示例和待抽取句子，生成三元组；用句子相似度选提示示例，属于上下文学习。
- **三元组 P/R/F1：** 预测三元组匹配标准三元组才计 TP，再套前面的公式。由于金标不穷尽，论文采用“局部封闭”设定，只考虑金标涉及的关系；空输出的 P/R/F1 设为 0。这个评测范围不能等同于“原文里所有可能的事实”。
- **其余四项指标：**

| 指标          | 具体计算                                              |
| ------------- | ----------------------------------------------------- |
| 本体符合率 OC | 关系标签属于允许词表的预测三元组数 / 所有预测三元组数 |
| 关系幻觉率 RH | 关系标签不属于词表的比例，即 `1−OC`                |
| 主体幻觉率 SH | 主体无法在原句或本体概念中词面找到的三元组比例        |
| 客体幻觉率 OH | 客体无法在原句或本体概念中词面找到的三元组比例        |

SH/OH 使用词干化后的子串检查；OC 在该版只检查关系词表，没有完整验证端点类型等本体限制。**一个完全没有原文支持的关系，仍可能通过以上四项检查**，只要两端名字出现过、关系标签合法。

**借鉴：** 将结构合规与事实匹配分开；不能直接用它的“幻觉率”代表医学语义错误率。[论文](https://arxiv.org/abs/2308.02357) · [PDF：§3–5](../references/text2kgbench_2023.pdf)

**6. Schema-Constrained Evaluation Framework（KG-LLM，2026）**

- **数据：** DocRED，6 类实体、96 类关系；实际实验仅抽取 **10 篇文档**，按长度、实体数和关系数分层。
- **方法：** 比较 Gemini 3 Pro、GPT-5.1、Claude Opus 4.5、Mistral 7B；将 schema 注入提示，约束/验证结构输出。框架支持一次抽整图，或先实体后关系。
- **实体评分：** 名称做 Unicode、大小写、空白和标点规范化，先精确匹配规范名，再匹配别名。这两类算 TP；子串匹配仅作为边界差异单独记录，不直接算正确。这里的实体主分数不是严格字符位置 NER F1。
- **关系评分：** 用 Hungarian 算法做预测与金标的一对一配对，避免重复计分。端点对齐、关系 ID 或规范标签完全匹配才算 TP；部分匹配只用于错误分析。汇总报 micro P/R/F1。
- **合规和稳定性：** 统计表外关系；在相同配置下多次推理，对每篇的实体/关系 F1 算均值、标准差。这是**分数波动**，不等同于直接计算两次输出集合的一致率。
- **人工复核：** 三人审查相同 10 篇文档的两阶段 Gemini 输出，分析金标漏标、标签差异、时效问题；不能用这份小样本排名推断普遍优劣。

**借鉴：** 固定别名规则、一对一匹配、部分正确仅用于诊断。[会议页](https://lrec.elra.info/lrec2026-ws-kgllm-21) · [PDF：§4–5](../references/schema_constrained_2026.pdf)

**7. Re-DocRED（EMNLP，2022）**

- **数据：** 重标 DocRED 的 4,053 篇 Wikipedia 文档，96 类关系；train/dev/test=3,053/500/500。重点是补关系漏标，而不是新建医学 NER 数据。
- **方法：** KD-DocRE、DocuNET、ATLOP 推荐可能漏标的关系，人工核实，再补充逻辑规则；评测额外使用未参与数据构建的 JEREX。各基线分别在原版和修订版训练/测试，并报告 3 次运行均值。
- **主评分：** 文档内的“头实体—关系标签—尾实体”匹配才算 TP，计算关系 micro F1。实体用给定的文档实体及共指分组表示，主任务不是从零识别每个实体 span。正确预测“无关系”不增加 TP；否则大量负例会把成绩虚高。
- **分层评分：** Freq. F1 只看最常见的 10 类关系，LT F1 看其余 86 类；Intra F1 看同句关系，Inter F1 看跨句关系。各子集重新统计 TP/FP/FN。
- **Ign_F1：** 用来降低训练集中已出现三元组带来的影响。正文概括为“忽略训练中出现的三元组后的 F1”；具体去重/忽略口径应沿用官方评分器，不自行理解为删除整个测试文档。

**借鉴：** 补漏能改变模型排名和分数解释；常见/罕见、同句/跨句分层很适合我们。高 F1 表示与修订金标更一致，不直接等于临床事实正确。[论文](https://aclanthology.org/2022.emnlp-main.580/) · [PDF：§3–4](../references/redocred_2022.pdf)

**8. Clinical KG（BioNLP，2024）**

- **数据：** 私有眼科病历中筛出的 320 份年龄相关性黄斑变性（AMD）记录，未公开；人工整理出 11 个治疗、8 个因素、8 个共现术语。
- **方法：** 把抽取变成带上下文的问答，例如“什么治疗 AMD”。比较 12 个模型，包括 BERT 系列问答模型、FLAN-T5/UL2、Llama 2 等；尝试零样本、少样本、指令和格式引导提示。根据回答概率、出现次数过滤，再用相似度合并重复表达，构建围绕 AMD 的图。
- **具体评什么：** 分别比较最终图里的 Treatment、Factor、Coexists_with 三类术语集合与人工列表。类别 `c` 的 `P_c=正确抽出的该类术语数/预测该类术语数`，`R_c=正确抽出的该类术语数/人工该类术语数`。它主要报告三类各自的 P/R。
- **为何不同：** 中心疾病固定，边的类别由问题类别决定，因此更接近“围绕一个疾病找对各类术语”，不是对每份病历逐个检查任意实体对、关系方向和证据。没有独立的严格 span NER F1；正文也没有充分写清预测与人工术语的所有同义匹配细则。相似度合并预测是后处理，不能擅自当作评分的同义判定规则。
- **人工部分：** 先共同试标、再独立标注、共同仲裁；另分析结构输出与幻觉问题。人工仲裁流程本身不等于已经报告了标注者 κ。

**借鉴：** 适合学习问答式抽取与人工标注流程；其高 P/R 不能直接横比文档级完整 KG F1。[论文](https://aclanthology.org/2024.bionlp-1.23/) · [PDF：§4–5](../references/clinical_kg_2024.pdf)

**补充：CDR（BioCreative V，2016）**

1,500 篇 PubMed 文章，train/dev/test 各 500。它是共享任务，参赛者使用不同系统，并没有一个统一抽取模型。疾病识别/规范化任务比较文档内疾病概念 ID；关系任务比较文档内 **化学物质 ID—疾病 ID** 对，核心关系是“化学物质诱发疾病”。正确概念对计 TP，再计算 P/R/F1；同一概念在文中多次出现不等于多条关系。它不是“药物治疗疾病”任务，无法单独覆盖我们的治疗推荐标签。[任务论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC4799720/)

**三、推荐的一套综合策略**

下面的规模是起步建议，不是论文规定，也不保证稀有类别的分数已经稳定。

| 部分     | 建议内容                                                       | 回答的问题                               |
| -------- | -------------------------------------------------------------- | ---------------------------------------- |
| 主测试   | 100–200 篇/段人工金标：诊断文本、治疗摘要各 50–100，分别报分 | 模型在我们的实际使用场景中是否有效？     |
| 难例测试 | 约 40–60 条，单独报分                                         | 否定、方向、条件和多疾病文本会怎样出错？ |
| 公开对照 | 首选 GutBrainIE，沿用官方划分与原生标签                        | 方法换到公开医学任务上是否仍有竞争力？   |

若本轮只交付诊断抽取，就以诊断层为主要结果，治疗层标为迁移测试。不要把两者混成一个总分，掩盖某一场景的不足。

**怎么做人工金标**

1. **先用 20 篇试标。** 明确实体类型、关系含义、方向、长诊断条件的边界；这些样本用于改指南和调 prompt，不进入最终盲测。
2. **再选新的正式测试文本。** 按预定来源抽样，保留真实无关系文本。同一论文或同一诊断来源组的片段、改写版和结构化版不能跨训练/测试。
3. **两人独立标注，分歧交由第三人或领域专家仲裁。** 标实体、关系及支持证据；允许模型辅助，但必须从原文主动补漏。记录标注者一致性，未决项单列。
4. **测试冻结后再比较模型。** 不用测试结果挑 prompt 或 checkpoint；发生金标修订时，所有模型按同一新版重算。

难例重点放在：核心/伴随症状混淆、鉴别/排除诊断混淆、关系反向、否定与条件、长诊断标准、跨句证据、多疾病之间连错对象，以及无关系时乱连边。尽量取真实文本；人为构造的例子注明来源。

**看哪些指标**

主指标建议用**端到端关系 F1**：模型只拿原文，自己抽实体和关系；两端实体的概念及类型、关系标签、方向都对，才算一条正确关系。

| 指标                         | 用直白的话说                                               |
| ---------------------------- | ---------------------------------------------------------- |
| 关系 Precision / Recall / F1 | 抽出的有多少正确、该抽的找回多少，以及两者的综合表现       |
| 各关系类别 F1 和样本数       | 看总分是否掩盖了关键类别；样本太少就不下稳定结论           |
| 实体 F1                      | 看关系失败是否源于漏实体；精确原文边界与概念匹配分开报     |
| 给定正确实体后的关系 F1      | 帮助定位关系模块的问题，不能替代全流程成绩                 |
| 人工原文支持率               | 随机抽查预测关系：证据是否真的支持关系强度、否定及适用条件 |
| 输出失败率与成本             | 格式错误、截断、非法标签，以及每篇耗时和费用               |

评分前固定同义词/别名规则，仅用于评分；不能让一个宽泛概念匹配多个不同实体，也不能用“意思差不多”放过错误关系。重复边只算一次，失败样本仍保留在测试中。总分用汇总全部关系的 micro F1，并给出按来源抽样估计的不确定区间。

这里有一个重要边界：**关系 F1 衡量与金标的一致性，人工支持率衡量预测是否有原文依据。** 后者能帮助识别漏标，但不能在没有完整金标时替代召回率。若要声称能抽取剂量、频次等属性，还需另设属性评测。

**比较哪些模型**

建议先比较四组：未微调 Qwen3-8B、旧版整图微调模型、当前两阶段 SFT、一个强 LLM 直接抽取。预算允许，再加入生成训练银标的教师模型，观察学生与教师的差距。

所有系统使用同一原文、同一标签定义和同等可用信息；各自按适合的输出协议推理，最后统一评分。若要进一步证明“两阶段设计本身更好”，再做同底座、同训练数据的一步/两步对照；仅比较新旧系统，无法排除训练数据变化带来的收益。

**公开数据怎么选**

我优先推荐 **GutBrainIE**：它的专家测试集、质量分层和多层评分更适合建立可复用对照。按其原生标签适配或训练后评测，并说明使用的数据；这测的是方法的迁移能力，不能当作当前固定标签模型的直接成绩。

**MDIEC 可作为精神医学领域补充。** 但它的 `characteristic_of` 无法直接拆成我们的“核心/伴随症状”，`treatment_for` 也不等于“一线治疗”。此外，论文描述复核 500 篇，本项目已有盘点记录为 946 对标注文件，版本和划分需要先厘清，不能直接宣称复现论文。[已有数据盘点](../datasets/public/mdiec/MDIEC_inventory.json)

**我建议的实施顺序：20 篇试标 → 完成人工主测试和难例集 → 跑四组模型 → 再补 GutBrainIE 对照。** 第一轮最值得投入的是独立、尽量完整的金标和清楚的错误分析；不必一开始把所有公开数据集、全部标签和大量模型都铺开。
